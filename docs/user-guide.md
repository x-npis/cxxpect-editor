# User Guide

Create or open one `.cxxp` contract, edit it, and inspect diagnostics as they appear after a short pause. Click a diagnostic or press `F8` to move to an error. Dragging a `.cxxp` file onto the window opens it.

Shortcuts: `Ctrl/Cmd+N`, `Ctrl/Cmd+O`, `Ctrl/Cmd+S`, `Ctrl/Cmd+Shift+S`, `Ctrl/Cmd+F`, and `F8`. Native text editing provides selection, copy/paste, undo, and redo. Find/replace supports next-match navigation and replace-all.

Closing or replacing a modified document opens a Save / Discard / Cancel prompt. Cancelling a file dialog leaves the current document untouched.
